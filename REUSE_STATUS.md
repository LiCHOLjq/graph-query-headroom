# Release scope and reuse status

The project owner authorized public disclosure of the project's original code
and experiment measurements. This package is limited to offline analysis code
created for this study, generated timing/quality/count records, and derived
numerical tables. No third-party implementation or source dataset is bundled.

No open-source or data reuse license has been selected. In particular, public
visibility must not be described as an MIT, Apache, Creative Commons, or CC0
license grant. This repository contains no newly assigned blanket license.

The original dataset/vector/model/native-engine distribution rights have not
been established by this package. Those materials, node lists, and structured
graph requests are omitted. Their omission does not assert that redistribution
would necessarily be prohibited; it limits this release to the verified scope.

The numerical release is sufficient to reproduce the documented statistical
analyses. Repeating native experiments, reconstructing exact eligibility sets,
or independently establishing recall/legality requires separately obtained
source data and implementations under their respective terms.

`provenance/transformations.json` binds each selected file to its source-member
hash and records byte-preserving copies or explicit field projections. The
source archive is not required for offline reproduction and is not included.
Metadata removal never replaces or estimates a measured scalar value. Original
source hashes and public-projection hashes are distinguished.
