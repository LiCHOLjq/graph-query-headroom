# Cost-aware policy selection: numerical research artifact

This repository contains original offline analysis code and numerical experiment
records for cost-aware policy selection. It supports verification of retained
costs, feature-leakage controls, repeated timing experiments, and a prospective
same-graph/new-query evaluation. It does not execute the underlying graph engines.

## Reproduce

Use Python 3.11 or later. The tested analysis environment is Python 3.11.14,
NumPy 2.4.0, pandas 2.3.3, Matplotlib 3.10.9, and scikit-learn 1.8.0.
Install `requirements.txt` in a separate environment, then run:

```text
python reproduce.py --output recomputed
```

Use a new or empty output directory. The command verifies the release manifest,
recomputes medians from all released repeated-call records, runs six analyses,
refits the frozen leakage-control models, and compares generated CSV values with
the retained reference tables. It saves logs and `reproduction_report.json` in
the output directory. All original inputs and reference tables remain unchanged.
No server, credentials, network connection, model pickle, graph/index, or native
compiler is needed after dependencies are installed. Floating-point table
comparisons use relative tolerance 1e-10 and absolute tolerance 1e-12; PDF
creation timestamps are not compared.

## Contents and verification coverage

| Component | Included evidence | Recomputed checks |
|---|---|---|
| Retained BCR/EGR/RPE stages | Policy costs, frozen out-of-fold choices, measured inference times | Cost/choice joins, stage and configuration weights, paired intervals, exact sign flips and Holm adjustments |
| Feature availability | Admissible and post-execution scalar feature caches, frozen predictions and fold hashes | Same held-out configurations and hyperparameters; all three diagnostic feature modes refitted |
| BCR repeated timing | 122,880 timed calls; 960 retained queries; two sessions and four conditions | Raw medians, corpus/seed grouping, condition contrasts, frozen first-session choices evaluated in the second |
| Prospective evaluation | 204,800 timed calls; 3,200 new queries on the same five graphs; eight paths | Raw medians, ordering, paired bootstrap, Monte Carlo sign flips, seven-comparison Holm adjustment, original engineering criterion |
| Budgeted policy scan | 3,840 attempts, including all 488 censored attempts | Coverage, observed costs, conditional complete-case diagnostics; no missing cost imputation |
| Public-baseline calibration | 28,800 timed calls; 576 queries; three fixed search budgets and two internal controls | Total/component medians, scalar quality summaries, all budgets and all corpora |

Public stage names are **BCR**, **EGR**, and **RPE**. Historical field values
`JQ8`, `JQ10`, and `JQ13` map to those names; they remain unchanged in recorded
tables to preserve exact join keys. RPE legacy is a distinct sensitivity cohort.
Each stage has its own policy set, decision boundary, units, and empirical oracle;
raw milliseconds are not pooled across stages.

The deliberately invalid result-feature and direct-cost controls are diagnostic
leakage demonstrations. Their improvements are not deployable routing results.
Their cached scalar features are provided; recreating them from source graphs
is outside this numerical release.

## Interpretation limits

The prospective 1% engineering criterion **was not met**. Reproduction success
does not change that result. Its largest approximate simultaneous upper bound
is 1.018103231012578. The evaluation uses new queries on the same five graphs,
not unseen graphs. Block sign-flip inference assumes exchangeable signs under
the null; within-query policy ordering does not make it an exact assignment test.
RPE's three seed values/ranges are descriptive, not reliable large-sample CIs.

All timings are recorded observations. No new measurements are generated by
these scripts. Prewarming, mutable-state allocation, session chronology, and
timing boundaries limit generalization to other hardware/cache regimes. The
release retains negative effects, signed oracle excesses, and censored cases.

Graph data, database embeddings, derived query vectors, actual graph-node/result
lists, trained models, indexes, native engines, and third-party source code are
excluded. Opaque experiment query IDs and answer equality hashes are retained.
Quality/legality values are **recorded audit results**, not independently
revalidated here from the omitted graph data. The external implementation's
behavior is represented by its measurements, not by a redistributed library.
